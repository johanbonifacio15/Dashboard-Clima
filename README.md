# Dashboard del clima

Dashboard del clima hecho con HTML, CSS y JavaScript. Consume la API de [Open-Meteo](https://open-meteo.com/) y muestra el clima actual de una ciudad.

## Características

- Clima actual: temperatura, sensación térmica, humedad, viento y lluvia del día.
- Manejo de errores (sin conexión, timeout, límite de solicitudes) con botón de reintentar.
- Estado de carga.
- Tema claro y oscuro según el sistema.
